# Grocery Store Checklist

[Watch My Project Presentation](https://youtu.be/OSBHwL6qmCk)

## Project Description

The Grocery Store Checklist is a Python program that allows users to manage a grocery shopping list.

Users can:

- View grocery items
- Add grocery items
- Remove grocery items
- Mark grocery items as purchased
- Calculate the estimated grocery cost
- Exit the program

## Python Concepts Demonstrated

This project demonstrates concepts from Python Crash Course Chapters 1-7, including:

- Variables
- Strings
- Numbers
- Lists
- Dictionaries
- Tuples
- if/elif/else statements
- for loops
- while loops
- User input
- Functions
- Input validation

## Data Structure Design

The project uses a list containing dictionaries.

Each dictionary represents one grocery item and contains:

- Name
- Category
- Price
- Purchased status

A tuple is used for the fixed grocery category choices.
